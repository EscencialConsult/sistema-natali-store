# sistema-natali-store

ERP offline-first (PWA) de Modas Naty: notas de venta A5 y catalogo de productos.

- `app/`: React 19 + Vite + Tailwind v4 + Dexie + Supabase
- `Docs/`: planes, hallazgos y rediseno
- Entorno local: `cd app` → `npm install` (una vez) → `npm run dev` (también `npm test`, `npm run build`, `npm run lint`)

Secretos (`.env.local`) fuera del repo; ver `app/.env.example`.
